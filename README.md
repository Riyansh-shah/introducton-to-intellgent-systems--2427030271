# Fuzzy Logic & Hybrid Intelligent Systems (MATLAB)

This repository contains solutions for two intelligence-based control problems using MATLAB.

## Project 1: Washing Machine Fuzzy Controller
- **Type:** Mamdani Fuzzy Inference System.
- **Inputs:** Dirt Level, Load Size.
- **Output:** Cycle Time.
- **Logic:** Uses triangular membership functions to determine optimal washing duration.

## Project 2: Student Performance Predictor (ANFIS)
- **Type:** Hybrid Neuro-Fuzzy System (ANFIS).
- **Integration:** Combines **Fuzzy Logic** (interpretability) with **Neural Networks** (learning).
- **Learning Algorithm:** Uses a Hybrid Method (Backpropagation + Least Squares) to tune membership functions based on student data.
- **Goal:** Predict performance level based on Attendance, Assignments, and Test Marks.

## How to Run
Run the `.m` files in MATLAB (Requires Fuzzy Logic Toolbox).
